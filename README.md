# Toast n Taste – Food Ordering Website

A simple online food ordering platform with a responsive frontend and Java backend.

# Features
- Place food orders online
- REST API built with Java (Spark framework)
- Bootstrap-powered responsive UI
- MySQL database schema for storing orders

# Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Java (Spark Framework)
- Database: MySQL

# Run Locally
1. Clone the repo
2. Start backend with `java Main.java`
3. Open `frontend/index.html` in browser
4. Ensure MySQL is running and schema is applied
